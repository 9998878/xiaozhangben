# 小账本 2.16.0

一款给 iPhone 用的**纯本地记账 PWA**：没有账号、没有服务器、数据只存在你这台手机的浏览器里，断网也能记账。

**在线地址（HTTPS，永久有效）** → <https://9998878.github.io/xiaozhangben/>

手机用 Safari 打开这个地址 → 分享 → 「添加到主屏幕」，之后就和一个 App 一样，飞行模式下照样能记、能看统计。

## 2.16.0 更新了什么（账单解读）

1. **底部导航改成 5 槽等宽**：首页 / 解读 / ＋ / 统计 / 我的，中间的黄色「＋」仍是记一笔，320px 小屏也不挤。
2. **新增「解读」页**：把当月账目翻成 7 个分区的本地规则报告——核心结论、收支摘要、消费结构、收支变化、值得留意、行动建议、统计口径；支持 本月 / 上月 / 近3个月 / 近6个月。
3. **图表能钻取**：环图扇区和图例可点出分类明细，柱状图点某个月直接切报告，明细里的某笔流水还能继续点开详情。
4. **首页预算卡常驻**：没设置时一键去设置，设置后显示已用 / 预算 / 剩余，超支变红；快捷入口收敛为三格，不再重复放预算。
5. 全部计算仍在本机完成，没有上传、没有新增账号；数据库结构未变，旧备份可直接导入。

## 2.13.0 更新了什么（照片三件事）

1. **画质 = 手机相册原图**：选照片时不再重新编码，直接把相册里的原始文件字节存下来（照片卡片上会标「原件」）。旧版本会把照片压到长边约 1600px / JPEG 0.75 再存，2.13.0 起不压了 —— 拍多少存多少。
2. **张数不再限制**：一笔流水原来最多 3 张照片，现在不限张数（一次多选、分批添加都行）。缩略图按需解码、原图按需读取，几十张也不会把页面卡死。
3. **点开照片是全屏看原图**：点缩略图直接进全屏查看器，看到的 100% 是原图（不是放大后的缩略图），可以左右滑动、双指放大，点空白或按返回键退出。

两点提醒：

- 想看全屏原图用**相册右侧的缩略图**点开；如果点的是笔记／流水列表里的那张小图，走的也是同一条全屏通道。
- **以前存的照片不会自动变清晰** —— 旧版本已经压过再存进 IndexedDB 的照片，原图字节在原文件被清理后就找不回来了。新拍新选的照片从 2.13.0 起才是原图级。

## 为什么是这样一个仓库

这个仓库只托管 `手机版/` 目录里的**构建产物**（一个自包含的 `index.html` + Service Worker + 图标/启动图），作用就是给 PWA 提供一个带 HTTPS 的稳定来源——Service Worker 只在安全上下文里才能注册，没有 HTTPS 就没有真正的离线能力。

源码、构建脚本与完整文档不在这个仓库里，这里只放能直接跑的东西。

## 文件

| 路径 | 作用 |
| --- | --- |
| `index.html` | 整个应用（JS/CSS 全部内联，约 2.3 MB） |
| `sw.js` | Service Worker，预缓存 14 项资源；导航请求网络优先、3 秒超时回退缓存 |
| `manifest.webmanifest` | PWA 清单，`start_url` / `scope` 都是 `./`，可放在任意子路径 |
| `icons/` | 主屏幕图标 3 张（180 / 192 / 512） |
| `splash/` | iPhone 启动图 8 张 |
| `.nojekyll` | 关掉 GitHub Pages 的 Jekyll 处理 |

## 离线是怎么做到的

首次打开时 Service Worker 把上面这 14 项全部拉进本地缓存：

1. 之后任何一次打开（包括从主屏幕冷启动）都是先读缓存，**不依赖网络**；
2. IndexedDB（库名 `xzb2`）存账本、流水、预算、存钱目标，与网络无关；
3. 联网有新版时后台更新缓存，下次打开生效——所以偶尔需要重开两次才能看到新版本。

实测：断网状态下冷启动约 0.3 秒渲染完成，写入一笔流水后重载仍然存在。

## 隐私

- 没有埋点、没有第三方脚本、没有请求外发（除拉取本站自身资源以更新缓存）。
- 数据不在任何服务器上。清除 Safari 网站数据、或从主屏幕删除应用，数据会一起消失。
- 因此唯一可靠的备份方式是应用内 `我的 → 导出备份 → 导出 JSON`，请定期导一份存到「文件」或 iCloud。

## 装到手机上的步骤

1. iPhone 用 **Safari**（不是微信内置浏览器）打开上面的地址，等首页数字出现；
2. 点底部「分享」→「添加到主屏幕」→ 命名「小账本」→ 添加；
3. 从主屏幕图标启动一次，让它把离线缓存装完（第一次启动会闪一下启动图）；
4. 想验证真离线：开飞行模式，从主屏幕冷启动，能进「首页」并记一笔就成了。

## 更新

站点内容由构建产物直接推送，更新方式是把新的 `手机版/` 整目录重新覆盖推送一次（`sw.js` 与 `index.html` 必须同批更新，缓存名带版本号 `xzb2-v2.16.2`，新 SW 激活时会清掉旧缓存）。推送完成后手机上可能需要重开两次页面才会切到新版。
