# 小账本 2.19.0

## 2.19.0 更新了什么（AI 智能点评）

1. **记账成功后多一句俏皮点评**：记一笔保存成功，Toast 变成「已记一笔 · 点评」（例如记「抽烟 20 元」→「又抽烟？这钱买斤水果不香吗～」），停留 3.6 秒读得完；小助手一句话记账确认后也会在「搞定，新增 N 笔」后面补一条点评气泡。
2. **点评全在本机生成**：按「备注/分类关键词（20 组场景：烟酒奶茶咖啡外卖游戏打车房租工资红包等）→ 大额支出（≥500 元）→ 收入/支出通用池」挑一条，同池随机且不与上一条重复；转账不点评、收入只夸不损、看病买书给正向，单条最长 40 字。
3. **没有任何联网与模型调用**：没有 API Key、没有请求，离线照样出点评；点评模块任何异常都静默跳过，绝不影响记账主流程；不想要内容变化也没有——数据、备份格式完全不变。

## 2.18.0 更新了什么（拆包 + 应用锁 + 体验修复）

1. **打开更快**：应用从「一个大 HTML」拆成「一个入口页 + 15 个按需加载的小文件」（10 个页面 + 5 个共用模块），首屏只加载你要看的那一屏，其余等你点进去再取；首次打开要解析的代码量从 5.9 万行降到 2.5 万行以内。
2. **应用锁（新功能）**：「我的 → 应用锁」可设 4 位数字 PIN。设好后，冷启动、以及「离开超过 5 分钟」再回来，都要先输 PIN；连续输错 5 次起要等 30 秒，之后越错等越久，最长 15 分钟。**这把锁只挡界面、不加密数据**——能拿到这台手机里浏览器数据的人仍然读得到账目，真正的异地备份还是靠「导出 JSON」。
3. **忘了 PIN 怎么办**：只能手输「清空」清掉本机全部数据（含自动快照，**无法恢复**）。不想承担这个风险就别开锁，或者把 PIN 记在别处。
4. **体验修复**：3 处文案纠错（数据损坏提示、清空完成的提示），没有其它行为改动；数据格式与备份格式完全不变，旧备份照常导入，仍然是单个入口、断网可用。
5. **注意**：这一版产物从 14 个文件变成 **29 个**（多了 15 个页面/模块文件），离线缓存从 14 项变 **29 项**；升级后第一次打开可能需要重开一两次页面才会切到新版。

## 2.17.1 更新了什么（行左滑修复）

1. **左滑删除不再带动整页上下滚**：以前手指从一条流水往左划想删它，屏幕经常先被整页滚动抢走，行被弹回；现在行自己判定方向——明显横向就锁给行，明显纵向才交还给页面。
2. 手感不变：左滑出「编辑 / 删除」、轻点开详情、长按 0.5 秒开操作表，都和之前一样。
3. 没有其它改动：数据、账本结构、备份格式完全不变，线上与本地各版本照常打开。

## 2.17.0 更新了什么（小助手）

1. **首页右上角多了 ✨ 小助手**：一句话就能记账——「午饭 35 微信」「昨天打车 18 支付宝」，也能一次说多笔（单批最多 20 笔）。
2. **写之前先给你看**：逐笔显示金额、分类、账户、日期、备注；默认值标「已按默认补全」，和已有账目相似会提醒你再确认；点「确认写入」才真正落库，多笔一次事务，任一笔不合法就整批不写入。
3. **不只是记账**：还能改（金额 / 分类 / 账户 / 日期）、改收支类型、删、查（「这个月餐饮花了多少」），查完可一键跳到明细分月。
4. **撤销更准**：「我的 → 小助手 → 撤销历史」能按时间 / 来源 / 金额筛选；撤销只逆操作那一批，不会连带回滚你之后手动记的账。
5. **「记一笔」瘦身**：原来的「一句话」小输入框搬进了小助手，手动记账页更清爽。解析仍全部在本机完成——没有模型调用、没有网络请求；数据库结构未变，旧备份照常导入。

## 2.13.0 更新了什么（照片三件事）

1. **画质 = 手机相册原图**：选照片时不再重新编码，直接把相册里的原始文件字节存下来（照片卡片上会标「原件」）。旧版本会把照片压到长边约 1600px / JPEG 0.75 再存，2.13.0 起不压了 —— 拍多少存多少。

两点提醒：

- 想看全屏原图用**相册右侧的缩略图**点开；如果点的是笔记／流水列表里的那张小图，走的也是同一条全屏通道。

## 为什么是这样一个仓库

这个仓库只托管 `手机版/` 目录里的**构建产物**（一个入口 `index.html` ＋ 15 个页面/模块文件 ＋ Service Worker ＋ 图标/启动图），作用就是给 PWA 提供一个带 HTTPS 的稳定来源——Service Worker 只在安全上下文里才能注册，没有 HTTPS 就没有真正的离线能力。

源码、构建脚本与完整文档不在这个仓库里，这里只放能直接跑的东西。

## 文件

| 路径 | 作用 |
| --- | --- |
| `index.html` | 应用入口（壳层 JS/CSS 全部内联，约 1.17 MB / 34,115 行） |
| `js/screens/` | 10 个页面文件（首页、记一笔、明细、统计、解读、账户、账本、预算、设置、小助手），进入对应页面时才加载 |
| `js/modules/` | 5 个共用模块（数字键盘、图标选择、图表、一句话解析、助手内核），被页面按需加载 |
| `sw.js` | Service Worker，预缓存 29 项资源（入口 + 15 个页面/模块 + 静态资源）；导航请求网络优先、3 秒超时回退缓存 |
| `manifest.webmanifest` | PWA 清单，`start_url` / `scope` 都是 `./`，可放在任意子路径 |
| `icons/` | 主屏幕图标 3 张（180 / 192 / 512） |
| `splash/` | iPhone 启动图 8 张 |
| `.nojekyll` | 关掉 GitHub Pages 的 Jekyll 处理 |

## 离线是怎么做到的

首次打开时 Service Worker 把上面这 29 项全部拉进本地缓存：

1. 之后任何一次打开（包括从主屏幕冷启动）都是先读缓存，**不依赖网络**；
2. IndexedDB（库名 `xzb2`）存账本、流水、预算、存钱目标，与网络无关；
3. 联网有新版时后台更新缓存，下次打开生效——所以偶尔需要重开两次才能看到新版本。

实测：断网状态下冷启动约 0.3 秒渲染完成，写入一笔流水后重载仍然存在。

## 隐私

- 没有埋点、没有第三方脚本、没有请求外发（除拉取本站自身资源以更新缓存）。
- 数据不在任何服务器上。清除 Safari 网站数据、或从主屏幕删除应用，数据会一起消失。
- 因此唯一可靠的备份方式是应用内 `我的 → 导出备份 → 导出 JSON`，请定期导一份存到「文件」或 iCloud。

## 装到手机上的步骤

1. iPhone 用 **Safari**（不是微信内置浏览器）打开上面的地址，等首页数字出现；
2. 点底部「分享」→「添加到主屏幕」→ 命名「小账本」→ 添加；
3. 从主屏幕图标启动一次，让它把离线缓存装完（第一次启动会闪一下启动图）；
4. 想验证真离线：开飞行模式，从主屏幕冷启动，能进「首页」并记一笔就成了。

## 更新

站点内容由构建产物直接推送，更新方式是把新的 `手机版/` 整目录（**29 个文件**）重新覆盖推送一次（`index.html`、`sw.js` 与 15 个页面/模块文件必须同批更新，少推一个对应页就打不开；缓存名带版本号 `xzb2-v2.18.0`，新 SW 激活时会清掉旧缓存）。推送完成后手机上可能需要重开两次页面才会切到新版。
